Kebijakan Privasi

Dokumen ringkas untuk versi demo platform EduVerse.

Data yang disimpan

Versi demo menyimpan nama, email, dan status sesi di penyimpanan lokal browser. Data tidak dikirim ke server karena demo ini tidak memiliki backend.

Cookie dan penyimpanan lokal

EduVerse menggunakan local storage untuk mempertahankan sesi demo. Hapus data situs dari browser jika ingin menghapus akun demo.

Kontak

Pertanyaan terkait privasi dapat disampaikan melalui halaman dukungan ketika fitur tersebut sudah tersedia.
